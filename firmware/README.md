# Firmware de Demonstração com Blynk e ESP32

Este projeto é um exemplo simples de firmware para ESP32 que demonstra o envio e recebimento de dados utilizando a plataforma Blynk.

## Funcionalidades principais

- Conexão Wi-Fi configurada com credenciais definidas no código.
- Comunicação com a nuvem Blynk para controle remoto e monitoramento.
- Atualização do estado de pinos virtuais no Blynk com base em eventos.
- Envio periódico do tempo de atividade do dispositivo para o aplicativo Blynk.
- Exemplo básico para iniciar projetos IoT com ESP32 e Blynk.

Este projeto serve como ponto de partida para quem deseja desenvolver aplicações IoT utilizando ESP32 e a plataforma Blynk.
