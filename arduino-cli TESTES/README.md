# Projetos de Teste Arduino CLI

Este repositório contém uma coleção de projetos de teste e exemplos para desenvolvimento com Arduino utilizando o Arduino CLI. Os projetos abrangem diversas placas e plataformas, incluindo:

- Placas clássicas Arduino (ex: Arduino Uno)
- Microcontroladores ESP32 e ESP8266
- MicroPython em placas ESP32

Cada subdiretório contém um exemplo ou projeto de teste específico, como piscar um LED, leitura de sensores como o DHT22, escaneamento de redes Wi-Fi e implementações de clientes Wi-Fi seguros.

Estes projetos servem como exemplos práticos para aprendizado e testes de fluxos de trabalho com Arduino CLI e programação de microcontroladores.
