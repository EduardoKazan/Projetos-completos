# ESP NOW – Comunicação Peer to Peer com ESP32

Este projeto contém uma coleção de exemplos para comunicação peer-to-peer utilizando a tecnologia ESP-NOW em microcontroladores ESP32.

## Funcionalidades principais

- Modos de comunicação variados, incluindo transmissão em broadcast e comunicação unidirecional.
- Exemplos de envio e recepção de dados, como temperatura, entre dispositivos ESP32.
- Gerenciamento de endereços MAC para comunicação direta entre dispositivos.
- Demonstração prática do uso do protocolo ESP-NOW para comunicação eficiente e de baixa latência.

Estes exemplos são ideais para quem deseja aprender e experimentar a comunicação sem fio entre dispositivos ESP32 utilizando ESP-NOW.
