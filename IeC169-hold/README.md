# Projeto Adaptado do Canal INTERNET E COISAS

Este projeto implementa a função `hold`, que realiza uma espera ativa por um tempo determinado em milissegundos, utilizando a função `millis()` do Arduino.

## Funcionalidade principal

- Função para pausar a execução do programa por um intervalo de tempo especificado, permitindo que outras tarefas sejam processadas durante a espera com a função `yield()`.

Este código é útil para controlar temporizações em projetos de eletrônica e IoT, garantindo que o microcontrolador continue responsivo durante períodos de espera.
