# Projeto Decodificador de Controle Remoto IR

Este projeto utiliza um receptor infravermelho (IR) conectado a um microcontrolador ESP32 para capturar e decodificar sinais de controles remotos IR.

## Funcionalidades principais

- Recepção de sinais IR através do pino 32 do ESP32.
- Decodificação dos sinais IR utilizando a biblioteca IRremoteESP8266.
- Impressão dos valores decodificados no monitor serial em formato hexadecimal.

Este projeto serve como base para aplicações que envolvem controle remoto IR, permitindo a captura e interpretação dos comandos enviados por controles remotos.
