# Projeto Tago DHT11 Temperatura e Umidade

Este projeto utiliza um sensor DHT11 para medir temperatura e umidade, enviando os dados para a plataforma TagoIO via conexão Wi-Fi.

## Descrição

O sistema conecta-se a uma rede Wi-Fi e ao serviço TagoIO para enviar dados em tempo real do sensor DHT11, que mede temperatura e umidade do ambiente. Os dados são lidos continuamente e enviados para a plataforma para monitoramento remoto.

## Componentes principais

- Sensor DHT11 para medição de temperatura e umidade
- Módulo Wi-Fi para conexão à internet
- Biblioteca Tago para comunicação com a plataforma TagoIO

## Funcionalidades

- Conexão automática à rede Wi-Fi
- Leitura contínua dos dados de temperatura e umidade
- Envio dos dados para a plataforma TagoIO para visualização e análise remota
- Monitoramento via console serial para depuração

Este projeto é útil para aplicações de monitoramento ambiental com envio de dados para a nuvem.
