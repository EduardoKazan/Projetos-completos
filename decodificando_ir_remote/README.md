# Decodificando Controle Remoto IR

Este projeto utiliza um receptor infravermelho (IR) conectado a um microcontrolador Arduino para decodificar sinais de controles remotos IR.

## Funcionalidades principais

- Recebe sinais IR através de um receptor conectado ao pino 11 do Arduino.
- Decodifica os sinais IR e exibe os códigos hexadecimais correspondentes na porta serial.
- Utiliza a biblioteca IRremote para facilitar a recepção e decodificação dos sinais.

Este projeto é ideal para quem deseja aprender a capturar e interpretar sinais de controles remotos IR para aplicações em automação e controle remoto.
