# Projeto SimplePollRotatorLCD

Este projeto demonstra o uso de um encoder rotativo para controlar a exibição em um display LCD I2C.

## Descrição

O sistema utiliza um encoder rotativo conectado aos pinos analógicos A0 e A1 para detectar a posição do usuário. A posição atual do encoder é exibida em tempo real em um display LCD 16x2 com interface I2C.

## Componentes principais

- Encoder rotativo para entrada de usuário
- Display LCD 16x2 com interface I2C para exibição
- Biblioteca RotaryEncoder para leitura do encoder
- Biblioteca LiquidCrystal_I2C para controle do display

## Funcionalidades

- Leitura contínua da posição do encoder rotativo
- Atualização dinâmica do valor exibido no display LCD
- Interface simples para interação com o usuário

Este projeto é útil para aplicações que necessitam de controle rotativo com feedback visual em displays LCD.
