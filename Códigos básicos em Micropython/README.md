# Códigos Básicos em MicroPython

Este repositório contém uma coleção de exemplos básicos de código em MicroPython para microcontroladores, focando em leitura de sensores, controle de atuadores e comunicação via Wi-Fi.

## Principais funcionalidades

- Leitura de sensores de temperatura, umidade, luz, gás, pressão, distância ultrassônica, entre outros.
- Controle de motores, servos, relés e displays (OLED, LCD).
- Exemplos de conexão Wi-Fi, servidores web simples e envio de dados via HTTP e MQTT.
- Código didático para aprendizado e prototipagem rápida com MicroPython.

Este conjunto de códigos é ideal para iniciantes que desejam explorar as capacidades do MicroPython em projetos embarcados.
