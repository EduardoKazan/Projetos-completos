# Projeto Adaptado do Canal INTERNET E COISAS

Este projeto implementa a função `analogAverage`, que realiza a média de 100 leituras analógicas de um pino específico em um microcontrolador, como Arduino.

## Funcionalidade principal

- Função para suavizar leituras analógicas, calculando a média de múltiplas amostras para reduzir ruídos e obter valores mais estáveis.

Este código é útil para aplicações que necessitam de leituras analógicas precisas e estáveis, como sensores analógicos em projetos de eletrônica e IoT.
