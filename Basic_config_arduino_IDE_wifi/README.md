# Configuração Básica Arduino IDE WiFi

Este projeto fornece uma biblioteca simples e eficiente para configuração e leitura de sensores digitais, além do controle de LEDs em placas Arduino. É ideal para quem deseja iniciar projetos com Arduino IDE que envolvam sensores e atuadores, com potencial para integração com conectividade WiFi.

## Funcionalidades principais

- Configuração e inicialização de pinos para sensores digitais
- Leitura dos estados dos sensores digitais (alto ou baixo)
- Controle de LEDs com função para piscar em um pino selecionado
- Código modular e fácil de integrar em outros projetos Arduino

## Aplicações

Este projeto serve como base para desenvolvimento de sistemas embarcados que necessitam monitorar sensores digitais e controlar dispositivos, podendo ser utilizado em projetos de automação, IoT e prototipagem rápida.
