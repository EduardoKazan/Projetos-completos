# Driver de Acionamento para MCUs

Este projeto consiste em um exemplo simples de controle de um relé utilizando um microcontrolador, como Arduino.

## Funcionalidades principais

- Controle digital de um relé conectado ao pino 3 do microcontrolador.
- Alternância periódica entre os estados ligado e desligado do relé.
- Comunicação serial para indicar o estado atual do relé (LIGADO ou DESLIGADO).

Este projeto é ideal para quem deseja aprender o básico sobre controle de dispositivos externos, como relés, através de microcontroladores.
